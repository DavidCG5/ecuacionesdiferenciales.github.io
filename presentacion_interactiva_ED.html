Modelo E1-M2 — Aportes Constantes

El inversionista deposita $500.000 COP anuales adicionales. La E.D. se vuelve no homogénea.

ECUACIÓN DIFERENCIAL
P'(t) = 0.05·P(t) + 0.5
SOLUCIÓN (factor integrante)
P(t) = 12·e^(0.05t) − 10
INTERPRETACIÓN

El término −10 es el capital de "equilibrio negativo": si no se hubiera invertido el capital inicial, los aportes solos no generarían crecimiento hasta t ≈ 18 años. El término 12·e^(0.05t) domina rápidamente.

La inflación del 2% reduce la tasa efectiva al 3% anual. El capital crece más lento en términos reales.

Módulo 03 · Etapa 2

Modelos de Segundo Orden

Cuando el mercado tiene inercia y amortiguamiento. Cuatro modelos con fenómenos cualitativamente distintos.

Sistema Sobreamortiguado

P''(t) + 3P'(t) + 2P(t) = 0

Δ = b² − 4ac = 9 − 8 = 1 > 0 → Sobreamortiguado

r₁ = −1, r₂ = −2
P(t) = 4.1e^(−t) − 2.1e^(−2t)

💡 Las fuerzas de resistencia del mercado superan la recuperación. Sin aportes, el capital se disipa completamente.

P(t) → 0 cuando t → ∞ (sin estímulo externo)

Aportes Periódicos — Coef. Indeterminados

P'' + 3P' + 2P = 10·cos(t)
P(t) = −0.9e^(−t) + 1.9e^(−2t) + cos(t) + 3sin(t)

Parte transitoria: −0.9e^(−t) + 1.9e^(−2t) → 0

Parte estacionaria: cos(t) + 3sin(t)

Amplitud = √(1² + 3²) = √10 ≈ $3.16M COP — Capital sostenido indefinidamente.

Transitoria + Estacionaria = Solución completa

Cuasi-Resonancia — Variación de Parámetros

P'' + 3P' + 2P = 2e^(−t)

⚡ f(t) = 2e^(−t) comparte forma con y₁ = e^(−t) → Cuasi-resonancia

y_p = 2e^(−t)(t − 1) → factor secular te^(−t)
P(t) = (2.1 + 2t)e^(−t) − 0.1e^(−2t)

El capital tiene un máximo local alrededor de t ≈ 1 año, luego decae. Modela aportes que inicialmente ayudan pero son insuficientes a largo plazo.

Máximo local por cuasi-resonancia

Largo Plazo — Ecuación de Cauchy-Euler

t²P'' + tP' − P = t² (t > 0)
ECUACIÓN INDICIAL: n² − 1 = 0
n₁ = 1, n₂ = −1 → P_h = C₁t + C₂/t
P(t) = 0.55t + 1.117/t + t²/3

• 0.55t: crecimiento lineal (rendimiento base)

• 1.117/t: efecto decreciente de condiciones iniciales

• t²/3: crecimiento cuadrático dominante → P(10) ≈ $42M COP

Crecimiento cuadrático t²/3 domina a largo plazo
Módulo 04 · Transformadas de Laplace

Del dominio del tiempo al dominio de frecuencia

Resolución paso a paso del Modelo E2-M2 mediante la Transformada de Laplace. Expande cada paso.

¿Qué es la Transformada de Laplace?

ℒ{f(t)} = F(s) = ∫₀^∞ e^(−st) f(t) dt

Convierte una E.D. (dominio t) en una ecuación algebraica (dominio s). Las condiciones iniciales se incorporan automáticamente.

P(s) en el dominio de frecuencia compleja s

Resolución de: P'' + 3P' + 2P = 10cos(t), P(0) = 2, P'(0) = 0.1

ℒ{P''} + 3ℒ{P'} + 2ℒ{P} = ℒ{10cos(t)}
[s²P(s) − 2s − 0.1] + 3[sP(s) − 2] + 2P(s) = 10s/(s²+1)

Las condiciones iniciales P(0)=2 y P'(0)=0.1 aparecen automáticamente en la ecuación transformada.

(s²+3s+2)·P(s) = 10s/(s²+1) + 2s + 6.1
P(s) = 10s/[(s²+1)(s+1)(s+2)] + (2s+6.1)/[(s+1)(s+2)]

La ecuación diferencial se convirtió en una ecuación algebraica. Solo queda factorizar y aplicar transformada inversa.

(2s+6.1)/[(s+1)(s+2)] = A/(s+1) + B/(s+2)

Evaluando en s=−1: A = (−2+6.1)/1 = 4.1

Evaluando en s=−2: B = (−4+6.1)/(−1) = −2.1

P₁(s) = 4.1/(s+1) − 2.1/(s+2)
10s/[(s²+1)(s+1)(s+2)] = (As+B)/(s²+1) + C/(s+1) + D/(s+2)

C = 10(−1)/[(2)(1)] = −5; D = 10(−2)/[(5)(−1)] = 4; A = 1, B = 3

P₂(s) = (s+3)/(s²+1) − 5/(s+1) + 4/(s+2)
P(s) = −0.9/(s+1) + 1.9/(s+2) + s/(s²+1) + 3/(s²+1)

Aplicando ℒ⁻¹{1/(s+a)} = e^(−at) y ℒ⁻¹{s/(s²+1)} = cos(t):

P(t) = −0.9e^(−t) + 1.9e^(−2t) + cos(t) + 3sin(t) ✓

¡Idéntico al resultado de coeficientes indeterminados! La Transformada de Laplace verifica toda la Etapa 2.

1.er Teorema de Traslación

ℒ{e^(at)f(t)} = F(s−a)

Produce los términos e^(rt) de la solución homogénea.

2.do Teorema de Traslación

ℒ{f(t−a)U(t−a)} = e^(−as)F(s)

Modela aportes que comienzan en t=a años.

Teorema de Convolución

ℒ{f*g} = F(s)·G(s)

Capital total = respuesta al impulso * perfil de aportes.
